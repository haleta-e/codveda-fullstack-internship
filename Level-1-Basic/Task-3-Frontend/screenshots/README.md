## Tips for High-Quality Evidence

1. **Keep Backend Running:** Ensure `npm start` or `npm run dev` in `Task-2-REST-API/` is running so live cards from PostgreSQL render on the page.
2. **Standard Browsers:** Use Chrome, Edge, or Firefox. Press `F12` -> Toggle device toolbar for the mobile screenshot.
3. **PNG Format:** Save screenshots directly into this directory (`Level-1-Basic/Task-3-Frontend/screenshots/`).
